# AIworld

本仓库收录面向既有游戏的智能世界模拟接入方法与实施规范。

## 文档

- [通用游戏世界模拟接入指导书（Markdown）](docs/AI游戏世界模拟接入指导书_v1.0.md)
- [通用游戏世界模拟接入指导书（DOCX）](docs/AI游戏世界模拟接入指导书_v1.0.docx)

指导书适用于 RPG、经营、模拟、策略、沙盒和互动叙事等游戏类型，重点覆盖：

- 游戏考古、事实与规则分层
- 原生适配器、能力目录与结构化模型协议
- 人物状态、记忆、关系、因果和事件调度
- 多智能体、感知、时间尺度与延迟后果
- 校验、回退、安全、测试、运营和版本迁移

核心边界是：模型负责理解、提议和叙事；原生引擎或受控适配器负责最终状态判定与写入。
